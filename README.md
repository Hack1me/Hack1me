*Projet stratégique – Mise en avant du marché local*

<table>
  <tr>

### 💑 CERBEN – Application de gestion pour couples
*Projet mobile – Vie quotidienne et finances partagées*

<table>
  <tr>
    <td width="70%">
      <strong>Description :</strong><br>
      Une application mobile (React Native) permettant aux <strong>couples</strong> 
      de gérer leur quotidien, leurs tâches et leurs projets communs de manière 
      transparente et sécurisée. L'application repose sur une API REST robuste

      intelligentes pour garder le cap financier à deux.
